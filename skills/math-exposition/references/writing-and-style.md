# 教材式数学写作与语言风格规范

本参考合并了讲义结构设计原则（参考 Knuth、Halmos、Axler、Conrad、Gowers）与中文教材级数学写作的去 AI 腔细则，供起草与定稿自查使用。

---

## 一、全篇组织与主线保护

1. **先问题，后概念；从特殊到一般**：新定义之前先给具体问题、数值计算或几何现象，说明引入该概念的动机（例如先算 $n=1,2,3$ 再写一般情形，用“一般地，……”过渡）。
2. **先理由，后意义**：先完成推导或证明，再说明该结论能解决什么问题，不先高调吹捧公式有多重要。
3. **主线优先于前置铺垫**：按证明依赖顺序组织材料，高阶延伸放主干之后或附录。
   - **正例**（“从圆的切线讲到圆锥曲线的极线，并解释与偏导/Hessian 的联系”）：先推圆外一点的切点弦，再通过齐次化与极化推广到一般二次曲线，证明互反性与切点弦性质，最后用一节短小清晰的梯度/Taylor 展开说明解析联系。
   - **反例**：一上来从极限、导数、多元微分讲起，最后才仓促引入二次曲线——即便前置推导没错，也已经偏离主题。
4. **讲清楚联系的适用边界**：推导 $2T_P(X) = 2f(P) + \nabla f(P)\cdot(X-P)$ 后，应明确在曲线上（$f(P)=0$ 且正则）$T_P=0$ 与切线重合，而在曲线外切勿把极线混同于一阶 Taylor 线性化；对有心二次曲线的中心情形应交代无穷远直线；两点重合时称“与切线重合”，避免滥用“退化”。

## 二、定义、定理与证明规范

1. **记号少而一致**：首次出现必须交代含义与范围，不引入后文用不到的记号，不同对象（函数 vs 系数 vs 双线性型）不共用同一字母。
2. **条件与例外明晰**：每条定理写清定义域、充分/必要条件、边界情况与反例讨论（说明去掉哪个条件结论失效）。
3. **先说路线，推理不跳**：证明较长时先用一句话给出路线（“下面对 $n$ 施归纳”“先证必要性”）；省略平凡验证时诚实写“请读者验证”，不在主要难点处写“显然”“易得”；“反之”仅用于确实在证明逆命题时。
4. **调用外部定理须坦诚点名**：直接引用较深结论时指明定理名与所需条件，不把整章无关背景塞进正文，也不要假装几句带过就算严格证明。

## 三、例题与习题格式（去模板化八股）

- **标准形态**：**题目 $\to$ 思路（可选，1–3 句）$\to$ 解 / 证 $\to$ 点评（可选，1–2 句）**。
- **不强求机械四段式**：若题目直接计算或过渡自然，直接写 `example` 后接 `\begin{proof}[解]` 即可，不要为了凑栏目硬塞“分析”“回顾”“本题考查了……”。
- **典型写法示例**：
  ```latex
  \begin{example}
  [精确、自足的题面。]
  \end{example}
  % 仅当有关键破局点时，用一两句话简述思路（可省略）
  \begin{proof}[解]
  [完整推演与边界/特例核对。]
  \end{proof}
  % 仅当有可迁移判别或易错警示时，附简短注记或点评（可省略）
  ```
- **配图与习题**：配图紧邻对应论证，图注点明数学关系而非只写“示意图”；习题侧重变式、反例与方法迁移，解答统一放在文后或附录。

## 四、句法风格与去 AI 腔清单

### 1. 语气与连接词
- 像老师在黑板前边写边讲：短句、陈述句为主，少用空泛修饰语；逻辑承接依靠**因为、所以、于是、从而、由……得、另一方面、反过来**自然轮换，避免连续多句用同一个词。
- 用**注、思考、探究**等教材惯用语，不用“总结、核心要点、方法提炼”。“注”只写 1–2 句易错或边界提醒。

### 2. 禁用词与反面对照
- **严禁出现**：核心思想、关键在于、本质上、神奇、巧妙、瞬间、让我们（一起）、是不是很……、非常重要、重中之重、值得注意的是、深度联系。
- **严禁形式**：感叹号（`！`）、表情符号、破折号高频插入解释、三连排比、与数学模型无关的生活化比喻、用大段无序要点列表替代连贯推理。

> **AI 腔（禁止）**：
> **等比数列求和公式是重中之重！** 让我们来看看这个神奇的公式……💡 错位相减非常巧妙——显然 $q=1$ 时 $S_n=na_1$。
> **关键在于**利用基本不等式——这是核心方法！

> **教材式（推荐）**：
> 等比数列 $\{a_n\}$ 的首项为 $a_1$，公比为 $q$，前 $n$ 项和为 $S_n = a_1 + a_1 q + \dots + a_1 q^{n-1}$。①
> 注意到右边每一项乘 $q$ 就得到它的后一项，将 ① 式两边同乘 $q$，得 $qS_n = a_1 q + a_1 q^2 + \dots + a_1 q^n$。②
> ① 与 ② 的右边只有首尾两项不同，作差得 $(1-q)S_n = a_1 - a_1 q^n$。当 $q \neq 1$ 时，$S_n = \frac{a_1(1-q^n)}{1-q}$。当 $q=1$ 时，上式分母为零不能套用，此时各项均为 $a_1$，故 $S_n = n a_1$。
> **注**：使用求和公式前先判定 $q$ 是否等于 $1$；当 $q$ 含参数时须分类讨论。

### 3. 符号与排版自查
- **不以符号起句**：写“由 $x > 0$，根据基本不等式……”而非“$x>0$，$x+\frac{4}{x}\ge 4$。”
- **正文禁用逻辑缩写符**：不写 $\therefore$、$\because$、$\forall$、$\exists$，用“因为”“所以”“对任意”“存在”替代。
- **标点与间距**：行内公式 `$...$` 或 `\(...\)` 嵌在完整句子内；公式内部及行间公式末尾随文带英文标点；不在正文中为了制造强调效果而到处加粗或框选非定义/非定理文字。

## 五、交付前逐条核对清单

- [ ] 每个新概念前都有具体问题或示例引入动机
- [ ] 全文没有无根据的跳步，“显然/易得”经得起推敲
- [ ] 定理/公式条件完整，必要处配反例或退化/无穷远情形讨论
- [ ] 例题无机械“分析—解—回顾”模板，且未出现“本题考查了……”
- [ ] 全文搜索不到禁用 AI 腔词汇、感叹号、表情符号、高频破折号插入与对话体（如“你记得基本正确”）
- [ ] 记号全程唯一一致，无符号开头句与裸 $\because/\therefore/\forall/\exists$
