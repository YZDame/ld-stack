# 数学讲义写作与 LaTeX 规范（Math Exposition）

以教材与成熟数学教师的口吻产出结构完整、推演严密、克制耐读的中文数学讲义（除非用户明确要求其他语言）。

本技能负责**原创与改写场景**下的数学主线、语言风格、定理证明与 LaTeX 排版。如输入是扫描件、手写板书照片或未转录 PDF，请先使用 `doc-ocr` 提取原始文本与配图；在具备工作区规范（如 `AGENTS.md`）的仓库中，项目路径、档案卡与 `REVIEW.md` 契约以工作区 `AGENTS.md` 为准。

---

## 1. 建立清晰的数学主线

- **先定目标与受众**：明确切入问题、核心结论、先修假设与交付形式，用一句内部主旨句约束全文，不偏离主线。
- **遵循依存顺序**：优先从具体问题或对象出发（特殊情形 $\to$ 一般结论 $\to$ 证明机制 $\to$ 应用与反例 $\to$ 延伸）；相关高阶理论置于主体之后或附录，不用大段前置课程淹没主题。
- **尊重用户给定提纲**：保留用户提供的章节脉络与已认可的推导路线，修正错误与缺漏前提，而不擅自偷换主题。
- **叙述与环境配合**：定义、定理、引理之间用流畅的衔接文字推进，避免干瘪的“定义—定理墙”。

## 2. 教材式数学语言与去 AI 腔

动笔及自查时务必阅读 [writing-and-style.md](references/writing-and-style.md)。核心硬约束如下：

1. **先问题，后概念；先理由，后意义**：引入新概念前先给具体例子或计算动机；先完成推导或证明，再说明用途，不在推导前空喊“非常重要/核心思想”。
2. **明确对象与前提**：先说明记号含义与集合/正则性假设（不重载同一字母）；区分充分条件与必要条件、局部与全局、重合与真正退化。
3. **推理完整诚实**：关键步骤不跳步；外部结论须点名引用；“显然”“易得”仅限读者一眼可见之处，不在难点处敷衍。
4. **例题结构自然克制**：统一采用 **「题目 $\to$ 思路（可选，仅在关键转折处用 1–3 句点破）$\to$ 解 / 证 $\to$ 点评（可选，仅在有迁移价值或易错分辨时附 1–2 句）」**。**严禁**对每道例题机械套用“分析—解—回顾”八股或“本题考查了……”套话。
5. **句式与标点规范**：
   - 逻辑连接词（因为、所以、于是、从而、由……得、另一方面、反之）自然轮换；**严禁滥用感叹号、表情符号、三连排比、破折号高频插入，以及“关键在于 / 本质上 / 神奇 / 巧妙 / 让我们一起 / 重中之重 / 值得注意的是”等 AI 腔词汇**。
   - 正文不用 $\therefore$、$\because$、$\forall$、$\exists$ 替代自然语言；行内公式嵌于完整句子中，中文语境用中文标点，公式内部及行间公式末尾随文带英文标点（`,` 或 `.`）；句子不以裸数学符号开头。
   - 保持版面克制：只给正式定义、定理、注、思考等栏目使用环境或加粗，不用小标题切碎推理段落，不附强行凑数的摘要或教学建议总结节。

## 3. 数学严密性自检

交付前逐项核对：
1. 定理条件是否覆盖所有论证需求（分母非零、梯度的正则性、边界/无穷远点、实复域区分）。
2. 代数等价变形与几何直观是否在相同前提下成立，反例与特例是否给出。
3. 所有数值计算、符号代换与引用定理均独立验算无误；练习与正文对齐且解答与题干分开（或按用户指定置于文末/附录）。

## 4. LaTeX 模板与编译规则

阅读 [evan-template-notes.md](references/evan-template-notes.md) 了解 `evan.sty`（2025 版）与中文排版细节。

### 工作区优先原则（极重要）
- **若当前工作区存在 `AGENTS.md` 或顶层 `templates/` 目录（例如 `latex` 仓库）**：
  - **严格遵守工作区的模板矩阵与根 `.latexmkrc` 的 `TEXINPUTS`**：直接写 `\usepackage[chinese,sexy]{evan-zh/evan}`（或其他工作区模板名），**绝不要**使用 `../templates/...` 相对路径，也**绝不要**把 `.sty` / `.cls` 复制进讲义子目录！
  - 编译统一使用工作区编译脚本（如 `sh scripts/build-xelatex.sh path/to/main.tex`）。
- **若在工作区之外创建独立便携源码包**：
  - 使用 [assets/evan.sty](assets/evan.sty)（2025 版，原生支持 `xeCJK` 与 `[chinese]`）搭配 [assets/textbook-template.tex](assets/textbook-template.tex)，或使用 [assets/ctex-mini-paper-template.tex](assets/ctex-mini-paper-template.tex) 作为轻量讲义/微专题起点。

### 通用排版与编译规范
- 使用 XeLaTeX 编译（推荐 A4、2 cm 页边距、11 pt 正文），采用 `\(...\)` 与 `\[...\]`（不用 `$$`），长推导用 `aligned`。
- 数学插图按场景选用 **TSQX / Asymptote**（平面几何）、**GeoGebra (`--tikzonly`)**（解析几何/函数交点）或 **Matplotlib 矢量 PDF**（统计/数值/函数族），严禁用位图 AI 生图替代精确几何图形。
- 生成 PDF 时至少编译至交叉引用稳定（`latexmk -xelatex`），检查 `.log` 中的错误、未定义引用、缺字与 Overfull 警告，并将渲染页转为图像目视核查版面后再交付。
